# CleanVM

A browser-only, performance-focused VM setup based on BlobeVM, optimized for a minimal desktop experience.

## Overview

CleanVM is a lightweight virtual machine environment designed to run in the browser with a streamlined setup. It defaults to i3, keeps the installation minimal, and installs only the required browser experience for a clean, fast workflow.

## Default setup

- Desktop environment: i3
- Default browser: Helium Browser
- No extra default desktop apps like Discord, Minecraft, Steam, or other browser alternatives
- Minimal app bundle focused on utility and performance

## Installation

Start with a blank GitHub Codespace and run:

```bash
curl -O https://raw.githubusercontent.com/laserdg/CleanVM/main/install.sh
chmod +x install.sh
./install.sh
```

## Project goals

- browser-only VM experience
- performance focused
- minimal default software footprint
- no unnecessary app clutter
- default to i3 and Helium

## Notes

This project is a clean, stripped-down fork intended for a focused browser and desktop experience without the extra default apps common in heavier setups.
